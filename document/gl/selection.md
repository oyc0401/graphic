# 📐 **`SelectionManager` 완벽 가이드 (히스토리 연동용)**

이 문서는 **히스토리 기능**을 개발할 때, 선택 영역(`Selection`)을  
정확히 저장하고 복구할 수 있도록 `SelectionManager`의 구조와 동작을  
매우 명확히 설명하는 문서입니다.

---

## 🖼️ **SelectionManager의 핵심 목적**

SelectionManager는 다음의 두 가지 핵심 역할을 수행합니다:

1. **선택 영역(Selection)** 을 관리하고 렌더링합니다.
2. **선택된 픽셀 데이터를 별도 텍스처에 저장하여 이동, 크기 변경, 붙여넣기 등의 편집 작업을 가능하게 합니다.**

히스토리 구현 시에는 **선택된 영역의 이미지 데이터뿐 아니라, 선택창의 위치와 크기 정보까지 저장해야 합니다.**

---

## 🗂️ **주요 데이터(필수 저장해야 할 항목)**

히스토리에 저장해야 할 주요 데이터는 다음과 같습니다:

- `x, y`: **선택 영역의 위치**
- `width, height`: **선택 영역의 크기**
- `originalWidth, originalHeight`: 원본 선택 영역 크기 (크기 조정 전)
- `selectionTex`: **원본 선택 이미지 텍스처 (크기 변경 전 이미지)**  
- `renderedSelectionTex`: **화면에 렌더링될 선택 이미지 텍스처 (최종 이미지)**

즉, **선택창의 이미지 데이터와 위치/크기 상태 모두** 저장해야 합니다.

---

## 🎯 **선택 영역의 동작 흐름**

SelectionManager의 핵심 동작은 다음 3단계로 요약됩니다.

### 🔸 1. 선택하기 (`select()`)

사용자가 특정 영역을 드래그하여 선택하면:

- 선택한 영역을 **기존 레이어에서 복사**하여 `selectionTex`에 저장합니다.
- 선택 영역을 기존 레이어에서 투명하게 지웁니다.
- 크기 조정된 텍스처(`renderedSelectionTex`)로 복사하여 화면에 렌더링 준비를 합니다.

### 🔸 2. 붙여넣기 (`paste()`)

외부 이미지(`ImageBitmap`)를 붙여넣을 경우:

- 해당 이미지를 바로 `selectionTex`에 저장합니다.
- 붙여넣은 이미지 위치와 크기를 설정하고, 렌더링 텍스처에 반영합니다.

### 🔸 3. 적용하기 (`applySelection()`)

- 선택 영역을 레이어에 **최종 병합**합니다.
- 병합된 후에는 `selectionTex` 데이터가 레이어로 완전히 병합됩니다.

---

## ♻️ **히스토리 기능을 위한 정확한 활용법**

히스토리 기능을 구현할 때 SelectionManager는 반드시 다음을 저장해야 합니다.

### 🔸 **히스토리에 저장할 항목 (Undo/Redo 용)**

- 선택 영역의 **위치(`x, y`)**
- 선택 영역의 **크기(`width, height`)**
- 선택 영역의 **이미지 데이터 (`selectionTex`의 픽셀 데이터)**

이 정보가 있으면, 사용자가 Undo를 눌렀을 때 **정확한 위치와 크기의 선택 영역**을 화면에 복원할 수 있습니다.

### 🔸 **Undo 시 선택 영역 복원 방법**

Undo 시 다음 과정을 수행하면 됩니다:

1. 저장된 위치(`x, y`)와 크기(`width, height`)를 복원합니다.
2. 저장된 이미지 데이터를 다시 `selectionTex`에 업로드합니다.
3. `uploadRenderedTex()`를 호출하여 화면 렌더링 텍스처를 다시 설정합니다.
4. 화면을 다시 렌더링합니다.

이렇게 하면 Undo 시 선택창이 **정확히 원래 위치로 복구됩니다**.

---

## 🚨 **선택창 이동 후 Undo 처리 방법**

선택창을 드래그해서 움직인 뒤 Undo를 수행하면, **선택창이 초기 위치로 되돌아가야 합니다.**

- Undo 시 위치 복원 시에는 저장된 초기 좌표를 이용해  
  `setSize()` 메서드를 호출하면 위치를 바로 복원할 수 있습니다.

예시:

```js
// Undo 시 위치 및 크기 복원
selectionManager.setSize(savedX, savedY, savedWidth, savedHeight);
```

이렇게 하면 **선택창 위치와 크기가 Undo 시 완벽히 복구**됩니다.

---

## 🧩 **선택 이미지 데이터 얻기 (`getPixelData()`)**

히스토리에 저장하기 위해 선택 영역 이미지를 픽셀 단위로 얻으려면:

```js
const { pixels, width, height } = selectionManager.getPixelData();
```

이 함수는 최종 렌더링 텍스처(`renderedSelectionTex`)의 픽셀 데이터를 가져와 히스토리에 저장할 때 유용합니다.

---

## 📌 **선택 텍스처의 구분**

| 텍스처명 | 용도 |
|--------|-----|
| `selectionTex` | 원본 선택 이미지(원본 크기) |
| `renderedSelectionTex` | 화면 렌더링용 선택 이미지(현재 크기) |

- 사용자는 화면에서 **`renderedSelectionTex`** 이미지를 보고 있습니다.
- 하지만 히스토리 저장 시에는 주로 최종 렌더링 텍스처의 이미지(`renderedSelectionTex`)를 저장하는 것이 가장 정확합니다.

---

## 🔑 **최종 히스토리 연동 흐름 정리**

히스토리 연동을 위한 전체 흐름:

```
선택 작업 시작 (select 또는 paste)
  → 선택 영역 위치, 크기, 이미지 저장 (히스토리 stack에 저장)

선택창 이동/크기 변경 후
  → 위치와 크기를 변경하고 화면 재렌더링

선택 적용 (applySelection)
  → 선택 이미지가 레이어로 병합
  → 이 시점에 sourceTextureManager.uploadCurrent()를 호출해 이미지 저장

Undo 호출
  → 저장된 위치, 크기, 이미지를 SelectionManager에 복원
  → selectionManager.setSize(), 텍스처 업로드 후 renderingManager.render() 호출
```

이 흐름을 구현하면, 사용자가 선택창을 이동하거나 크기를 변경했을 때도 **정확히 Undo로 복원**할 수 있습니다.

---

## 🎉 **최종 요약**

- SelectionManager는 **선택된 영역의 이미지와 위치를 관리**합니다.
- 히스토리는 **선택창 위치, 크기, 이미지**를 모두 저장하고 복구해야 합니다.
- 선택창 이동 후 Undo 시 **초기 위치로 복원**되는 것이 핵심입니다.

이제 히스토리 연동에 필요한 모든 정보를 정확히 이해했습니다! 🔥
