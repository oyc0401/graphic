# Paintive

- 텍스쳐에는 비 프리멀티플라이드 알파로 저장한다.
- 최종 null 프레임버퍼에는 프리멀티플라이드 알파로 색을 넣는다.

- 모든 작업을 하고 난 이후에는 source텍스쳐에 현재 화면의 정보를 잊지 말고 꼭 업로드하기!
`sourceTextureManager.uploadCurrent()`
(이유: 시작 전에 하면 초기 실행 시간이 오래걸리고, 그래픽카드 지연때문에 드로우 순서가 뒤바뀔 수 있음!)

- 브러시 생명주기에 맞는 함수 모두 다 구현할 것.

- 렌더링 할 때에는 오프스크린에 그린 이후 null버퍼에 업로드 한다. (아직 오프스크린은 미구현)
